本轮完成原架构审查清单的实现复核与后续修复，发布本地清洗索引 `clean-20260905`，并通过真实浏览器操作生产构建进行验收。平台继续定位为通用会诊，不新增强制 animal_id。逐项技术债映射见 [原计划第6节](architecture_review_and_improvement_plan_2026-09-02.md)；可机器读取的汇总见 [指标文件](technical_debt_metrics_2026-09-05.json)。

## 1. 完成的改动

- Run 使用数据库时间租约、心跳和 execution_epoch 栅栏；旧 Worker 失去所有权后不能继续写事件、答案或扣费。启动恢复仅接管租约过期任务，取消、失败和终态持久化具备回归覆盖。
- 流式首包即时输出，其余 delta 按100ms/32个合并；PG NOTIFY 只在事务提交后触发，SSE共享监听及5秒兜底查询；答案、结算、终态事件原子提交。积分幂等在行锁/savepoint保护下处理唯一约束竞争。
- 记忆写入采用持久化 outbox，独立处理超时和重试，执行前再次检查用户偏好；回答终态不等待记忆服务。trace 有界、异步、采样，仅记录元数据。
- RAG 合并向量矩阵、类目行过滤、mmap 元数据和有界缓存；查询长度按token限制，重排成对预算分窗，文本哈希去重保留来源。dense/RRF 不沿用重排阈值，未校准时不把分数当作充分证据。
- 前端拆分 useRunStream；代际/abort守卫、停止等待终态、类型化SSE及运行时校验；48条游标分页、长历史虚拟化、完整导出、Admin/Settings懒加载、单实例响应式侧栏。
- 删除旧别名并迁移测试；邀请/重置令牌捕获后清除地址，注册不依赖整页刷新；管理员按角色请求接口。实操发现并修复搜索残留、移动导航遮挡、重答/首条标题、停止文案、个人资料即时更新、密钥关闭后残留、页内确认与审计资源ID。

## 2. 知识库清洗与可靠性

原始252,130,864字符，保留203,980,357字符，隔离42,911,341字符、91,757个块。这些计数不是严格相减关系，解析会归一化标记并重建表格。全部正文窗口通过来源跨度复核。

发布门禁绑定 manifest/taxonomy/validated 的哈希及报告哈希；制品改变后旧验收不能放行。prepare/embed拒绝覆写当前活动版本，publish原子切换taxonomy并保存previous_taxonomy。服务已重启且确认载入294,317块。原文、模型、向量、数据库和含书籍片段的原始报告不提交Git。其他机器部署须传输经校验release或重新构建，操作和回退见 [RAG README](../RAG/README.md)。
